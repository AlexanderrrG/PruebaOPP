# PruebaOPP


🍎 SOFTWARE ACADEMY UTA - SISTEMA ACADÉMICO 💻
¡Bienvenido! Este es el proyecto final de Programación Orientada a Objetos (POO) desarrollado por Alexander Gumana. El sistema es una solución integral que conecta una interfaz web moderna con la lógica robusta de C++ para la gestión de calificaciones.

🚀 Funcionalidades del Sistema
El software está diseñado para ser intuitivo y eficiente, ofreciendo las siguientes herramientas:

🧮 Operaciones Aritméticas: Un módulo para realizar cálculos básicos (Suma, Resta, Multiplicación y División) de forma rápida.

📝 Registro de Notas: Permite ingresar el nombre del estudiante y sus 5 notas del parcial.

📊 Análisis Inteligente: El sistema calcula automáticamente:

El Promedio final.

La Nota Mayor y la Nota Menor.

El Estado Académico (✅ Aprobado / ❌ Reprobado).

💾 Persistencia de Datos: Los resultados se guardan físicamente en un archivo resultados.txt para mantener un historial permanente.

🌐 Interfaz Web: Una réplica visual profesional en HTML/CSS con estética Rojo y Negro.

🛠️ Tecnologías Utilizadas
C++: Motor principal para la lógica de escritorio y manejo de archivos (fstream).

HTML5 & CSS3: Estructura y diseño de la interfaz de usuario con diseño responsivo.

JavaScript: Lógica interactiva en la versión web y persistencia en localStorage.

Markdown: Para la documentación de este repositorio.

📁 Estructura del Repositorio
/C++_Source: Contiene el código fuente main.cpp para Code::Blocks.

/Web_Interface: Contiene los archivos index.html y style.css.

resultados.txt: Archivo generado automáticamente con el historial de estudiantes.

📖 Instrucciones de Uso (C++)
Abre el proyecto en Code::Blocks.

Compila y ejecuta el archivo main.cpp.

Usa la Opción 2 para ingresar los datos de tus compañeros.

Usa la Opción 3 para confirmar el guardado. ¡Verás una confirmación en consola y el archivo .txt se actualizará al instante! 📂✨
